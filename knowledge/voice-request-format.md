# voice-request-format.md — 体験談の記入依頼フォーマット

> 初版: ライト作成（2026-06-13）。**要光さん確認**。
> メディスンホイールプログラムを受けた方に体験談をお願いするときに使う。
> 掲載の仕組み: 受領した原文を `content/voices/*.md` に移植 → ご本人最終確認 → 下書きPR → 光さんマージで公開。
> **原文の意味・表現は一切編集しない。** 唯一の例外は個人特定情報（実名・地名・社名・病名・第三者の識別情報）の伏せ字化で、その処理内容はご本人最終確認時に明示して同意を得る。誤字脱字の修正もご本人に確認してから。サイトの実装と分類は `src/lib/programs.ts`（10メニュー）が正典。

## 1. 送付用の依頼文

### A. LINE・メッセージ用（短い版）

```
このあいだは、おつかれさまでした。

ひとつお願いがあります。
今回の体験を、言葉にして残してもらえませんか。

ライトワークセンターのサイトに「Voices」という、
受けた人の声をそのまま載せるページを作りました。
名前は出ません。イニシャルと年代、職業の方向性だけです。

うまく書く必要はないです。
話し言葉のままでいいし、長さも自由。
書くのが面倒だったら、音声で送ってくれたら俺が文字に起こします。

下に質問を5つ置いておくので、
答えられるところだけ、自分の言葉で書いてください。

公開する前に、必ず本人に最終確認します。
出したくなくなったら、いつでも取り下げられます。
```

### B. メール・あらたまった依頼用

```
件名: 体験談のお願い — Lightwork Center

先日は、プログラムを最後まで受けてくださって、ありがとうございました。

ひとつ、お願いがあってご連絡しました。
今回の体験を、あなた自身の言葉で書き残していただけないでしょうか。

ライトワークセンターのサイトに「Voices」というページがあります。
プログラムを受けた方の体験談を、ご本人の許可のもと、匿名で掲載する場所です。
（参考: https://lightworkcenter.com/voices ）

掲載にあたってのお約束:

・名前は出ません。イニシャル・年代・職業の方向性のみ掲載します
・個人が特定されうる情報は、掲載前にすべて削除します
・いただいた文章は原則そのまま掲載します（こちらで書き換えません）
・公開前に、必ず掲載内容をご本人に確認していただきます
・公開後でも、申し出があればいつでも取り下げます

うまく書こうとしなくて大丈夫です。話し言葉のままで構いませんし、
長さも自由です。文章にするのが大変でしたら、音声メッセージで
お送りいただければ、こちらで文字に起こしてご確認いただきます。

次のセクションの質問に、答えられる範囲でお答えください。
全部に答える必要はありません。

お忙しいところ恐縮ですが、どうぞよろしくお願いします。

長島 光
Lightwork Center
```

## 2. 記入フォーマット本体（このまま送る）

```
━━━━━━━━━━━━━━━━━━━━
体験談 記入フォーマット
━━━━━━━━━━━━━━━━━━━━

■ 基本情報

※18歳未満の方の体験談は掲載をお受けしていません

・年代（例: 20代）:
・職業の方向性（例: アーティスト・経営者）:
  ※会社名や肩書きの詳細は不要です。方向性だけで大丈夫です
・受けたメニュー（あてはまるもの全部に○）:
  [ ] セレモニー
  [ ] 生活習慣の見直し（ディエタ30日）
  [ ] 伝統的な浄化（カンボ）
  [ ] リトリート
  [ ] 21日間プログラム（マイクロドージング）
  [ ] パワーアップ
  [ ] 継続サポート
  [ ] エコノミーパック
  [ ] アダムカドモン覚醒 イニシエーションパック
  [ ] VIPコース
・受けた時期（例: 2026年4月ごろ）:

■ 体験について（答えられるところだけで大丈夫です）

Q1. 受ける前、どんな状態でしたか？
    （そのとき抱えていたこと、行き詰まっていたこと、きっかけなど）



Q2. 受けようと決めたのは、なぜですか？
    （調べたこと、迷ったこと、決め手になったことなど）



Q3. セレモニーや実践のあいだ、何が起きましたか？
    （見えたもの、感じたこと、思い出したことを、そのまま）



Q4. 終わってから、日常はどうなりましたか？
    （変わったことも、変わらなかったことも、そのまま書いてください）



Q5. これから受けるかどうか考えている人に、伝えたいことはありますか？



■ 書き方について

・うまく書く必要はありません。話し言葉のままで大丈夫です
・具体的な病名・診断名・薬の名前は書かなくて大丈夫です
  （書かれていた場合は、確認のうえこちらで伏せさせていただきます）
・長さは自由です（数行でも、長くても）
・質問の順番どおりでなくても、全部に答えなくても構いません
・文章が大変なら、音声で送ってください。こちらで文字に起こして、
  あなたに確認してもらってから使います

■ 掲載についてのご確認（○をつけてください）

[ ] 匿名（イニシャル・年代・職業の方向性のみ）での掲載に同意します
[ ] 公開前に、掲載内容を自分で最終確認します
[ ] 公開後も、いつでも取り下げをお願いできることを理解しています

イニシャルの希望があれば（例: I. ／ おまかせでもOK）:

━━━━━━━━━━━━━━━━━━━━
```

## 3. 運用メモ（光さん・ライト向け）

### 受領してから公開まで

1. **受領** — テキスト or 音声。音声は文字起こしして、まずご本人に全文確認
2. **md化** — ライトに渡す。`content/voices/<内容ベースのslug>.md` に移植（原文の編集は伏せ字化のみ・slug/ファイル名に個人名を入れない）
   - frontmatter: `initial` / `age` / `profession` / `programs`（下の対応表）/ `title` / `excerpt` / `publishedAt` / `status: draft`（修正して再掲載するときは `updatedAt` も）
   - Q1〜Q5 の区切りは本文の `---`（⊙）に対応させる。回答が一部だけならあるものだけで構成
3. **コンプラ確認（機械＋目視の二段。機械だけで安心しない）**
   - `npm run check:compliance` は**既知のNGワードの文字列一致のみ**を検出する。**自由記述の効果証言は機械では拾えない**（「〜が治った」「〜に効いた」「修復できる」「中毒の治療」など、リスト外の語で効果を断定する文は素通りする）
   - だから本文は必ず**光さんが目視**で確認する。見るポイント: ①効果・治癒の断定（治った/効いた/修復/治療/改善した 等）②病名・診断名・薬剤名 ③医薬品と誤認されうる語（「薬」「処方」等）④第三者（家族・友人等）が特定されうる記述
   - 引っかかったら**運営側で書き換えない**。伏せ字化の提案 or 本人への書き直し依頼を、理由を添えてご本人に戻す。判断に迷う表現は専門家確認
4. **本人最終確認** — **本文の文面コピー（伏せ字化した箇所を明示したもの）をご本人へ送って確認**。OKの返事をもらってから次へ
   ※`status: draft` はサイト上に描画されない実装のため、プレビューURLでの確認はできない（draftプレビュー機能は将来課題）
5. **公開** — `status: published` にして下書きPR → 光さんマージ

### この依頼文・質問が守っていること（変更時もここを守る）

- **効果を誘導しない。** 「どんな効果がありましたか」とは聞かない。「何が起きましたか」「どうなりましたか」と中立に聞く。Q4は「変わらなかったことも」とセットで聞く（薬機法: 運営側が効能の証言を求めた形にしない）
- **本人の言葉のまま。** 編集・要約・盛りは一切しない。直したいときは本人に書き直してもらう
- **取り下げ自由・本人最終確認**を、依頼の時点で約束する
- **病名・診断名は求めない**（Q1の聞き方を「状態」に留める。書かれたら伏せる）。18歳未満は掲載しない
- 本文に登場する**第三者**（家族・友人等）が特定されうる記述は、本人最終確認時に伏せ字化を相談する
- 「ぜひ」「絶対」「おすすめ」で押さない。書くかどうかも自由
