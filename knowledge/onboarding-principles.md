## 0. 逡巡層とは

確信層（既に本物を探している人）と違い、**憧れと恐怖が同居して動けない層**。代表ペルソナ「みゆきさん」（※固有事情は内部資料。記事本文には出さない）。

## 1. 役割分担（前提）

- **光さん** = 迎える人 / 受付 / 伴走（メディアで抵抗を溶かす"入口"）
- **朝陽** = プログラム本体 / 施術（iboga.jp）
- 逡巡層の動線：**メディア → 光さんの受付 → 朝陽の iboga.jp メディスンホイール**
- 既存の「経営者向けライン」とはトーンを交わらせない（別ライン）

## 2. 背骨 = 4原則

1. **説得しない** — 情報と物語を置き、判断は本人に返す
2. **抵抗の正常化** — 「怖くて正常」「迷って健全」「途中で止まっていい」を構造で配置。※「除去（煽って消す）」は禁止
3. **無人の聖域** — 急かさないUI。何度でも来て、何も決めずに帰れる
4. **押さない ≠ 動かさない** — 判断は返すが、扉の在り処（次の一歩）は常に示す

## 3. 絶対の歯止め（最重要・S7で必ず確認）

- サイトは読者の恐怖を【**当てにいかない**】。「あなたの本当の恐怖はこれです」と当てる診断にしない
- 見立ては内部の設計仮説に留め、**表に出すのは選択肢だけ**
- 「**申し込まない**」という結論も等しく成功とする。※これを失敗扱いした瞬間、サイトは説得装置に堕ちる

## 4. 抵抗のレイヤー（並列。順序も比重も人による）

| レイヤー | 緩め方 = 攻略でなく「選択肢を置く」 |
|---|---|
| 0. 実務的障壁（情報/お金/健康/時期）※「浅い」と切り捨てない | 事実を過不足なく。「まだ早い」も正当な答え |
| 1. 認知的未知 | 既知化（神経科学＋伝統。science-refs.md） |
| 2. 安全性の恐怖 | 事実の透明化（スクリーニング/心電図/断る権利） |
| 3. 手放しへの恐怖 | surrender の再定義（§5 参照） |
| 4. 社会的後ろめたさ | 正統性＋非・宗教性＋自律尊重 |
| 5. 行動の停滞 | 決断負荷の軽減／「途中で止まっていい」 |
| 6. 自己否定の歴史 | 「違い」を役割・視点へ再フレーム |

## 5. ガードレール（`compliance.md` に従う＋逡巡層特有）

- 効果断定禁止（治る/効く/治療/改善/不安が消える）。「安全です」と言わず**事実を列挙**して読者に判断させる
- 「医療行為ではない」明記。医療を否定せず、必要時受診を促す
- イボガ／イボガインは日本の麻薬別表第1に非掲載＝麻薬指定なし（2026-06確認）。「麻薬指定」「海外法域でのみ」と書かない。ただし医療効果の断定は薬機法上禁止／施術場所は断定しない
- **身体疾患（斜視等）を起点に導線を引かない**。扱うのは「人と違うと感じてきた経験」一般の心理に限定
- surrender を「可逆・必ず戻る」と**生理学的に断定しない**。伝承＋体験者の語りの枠で（compliance.md の伝承マーカー同伴ルール）。神経科学を出すなら「体験中の一時的な自己感覚の変化」と「その後の持続的な回路の組み直し（修復）」を別レイヤーとして正確に分ける
- 緊急性演出（残席/期限/割引）禁止。出口を常に明示（カルト性回避）
- **自律尊重 ＞ CV**

## 6. S7 倫理ゲート 追加項目（品質ゲートで機械的に確認）

1. 特定身体疾患を起点にした導線になっていないか
2. 恐怖を"当てる"診断になっていないか（§3）
3. 緊急性演出（残席/期限/割引）が無いか
4. 出口（申し込まない自由・次の一歩）が明示されているか
5. 「申し込まない」を等価に扱っているか
